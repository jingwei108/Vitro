## 3. 差分过程中修掉的移植缺陷（红→绿留痕）

1. **实参捕获数组别名**：`args.push(current); current.clear()` 引用语义清空已存实参——`MAX(1,2)` 展开双参同值（diff g000002 抓出）。
2. **存根 include 行号公式**：`L − N − 2 + k` 误套哨兵公式——存根路径 Rust 无哨兵包装，正确为 `L − N + k`（负行号是 oracle 行号补偿缺陷的忠实复刻）。
3. **u8 前缀列号基准**：Rust 的 `string_literal()` 起点在引号处（不含 u8）而 byte_off 记账在 u8 起点——拆分 `span_start` 双基准。
4. **string/char 列号基准**：Rust `make_token(ty, &源切片)` 用源切片长度反推列后才覆盖 text 为解码值——复刻源切片基准（value 与源拼写不等长时两口径分叉）。
5. **gen_stubs `%q` 双重转义**：已转义文本经 `%q` 再转义，存根全部挤成一行 + 30 条 E1001——`%s` 修复。

## 5. 决策登记（与勘察报告的偏差）

1. **TokenType 维持 flat 116 变体**（勘察 ⑤-4 曾建议分层）：L1/L2 差分锚要求 `to_name` 与 Rust Debug 逐字节一致，flat 消除映射噪声；diag 137 臂先例已证工程可行。
2. **公共类型独立包 `lexer/token`**：MoonBit internal 包不可被 facade 外导入且 facade↔internal 不得成环（实证：cmd/dump_tokens 导 host 被 internal 可见性规则拒绝）——勘察 ⑨ 的 `internal/{source,pp,host}` 三包调整为 `token`（公共）+ `internal/{scanner,pp,host}`。
3. **StubsFirstProvider 删除**：trait 不能作字段类型（语言约束）——存根优先逻辑单源在 pp/resolver。
4. **`SourceProvider` 为 `pub(open) trait`**：默认 readonly trait 跨包不可 impl。
5. **`substring` deprecated warning 留置 23 处**：本安装 core 的切片形态（`str[:]`）返回 StringView 且 raise，与 String 类型系统摩擦；substring 是可用形态，留置登记（非阻塞）。
6. **语料生成器为 `.mbtx`**（总计划锚点名要求）——但受"front-matter import 无法解析本地 module 包"限制，**生成器不 import lexer 包**（纯生成逻辑 + x/fs 落盘），词法侧批量出口用 workspace 内 main 包（`cmd/dump_tokens`）。
7. **rust 侧改动面**（防线维护）：Lexer 加 2 个 `pub(crate)` 记账字段（byte_pos / last_start_byte）+ advance 一行 + next_token 一行 + `tokenize_raw` 方法 + CLI 子命令——生产路径零语义变化（tokenize/tokenize 行为不变，全部既有测试通过）。

## 6. 遗留

- L3 诊断层对拍（错误消息逐字比对）未纳入本片锚点（验收锚 = L1/L2）——L2 已比 errors/warnings **计数**；消息文案已照搬 Rust（W1018/W1019/E1017/E1016/E1021 等），逐字对拍随 S3 parser 片的 E1-E4 管道统一建。
- `#warning` 的 W 级 severity 精确化：需 diag 码表加 W 码（enum 加变体对下游穷尽 match 是破坏性变更，随 diag minor 版本单独裁定）。
- 差分驱动未进 CI（本轮全绿基线已留痕；CI 接线随 S3 片的 E1 全量管道统一建）。
